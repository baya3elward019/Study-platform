# سحابة Study Lab

منصة مراجعة شخصية لشهادات Azure، مبنية حوالين المراجعة المتكررة (spaced repetition). المسار الحالي **AZ-104**، وبعده AZ-500.

A personal study platform for Azure certifications: scenario questions, spaced repetition, flashcards, timed mock exams, and a study log. Plain HTML/CSS/JS, no build step, no backend.

## فيها إيه

- **193 سؤال سيناريو** على AZ-104 بأربع أشكال: اختيار واحد، اختيار متعدد، ترتيب خطوات، وعبارات Yes/No. الأسئلة بالإنجليزي والشرح بالعربي.
- **مراجعة النهارده**: المستحق + أسئلة جديدة. اللي تغلط فيه يرجع بكرة، واللي تجاوبه صح يرجع بعد 1 ← 3 ← 7 ← 16 ← 35 يوم.
- **«مش عارف»**: بيورّيك الإجابة والشرح، والسؤال بيرجعلك.
- **45 بطاقة سريعة** للأرقام والحدود والفروق اللي بتتسأل كتير.
- **خريطة الامتحان**: المحاور الخمسة بأوزانها الرسمية ونسبة إتقانك.
- **المحاور**: الـ skills measured الرسمية كـ checklist، وتدريب على كل قسم.
- **بنك الأسئلة**: بحث وفلترة بالمحور والحالة، وفتح أي سؤال لوحده.
- **علامات وملاحظات**: علّم على سؤال ⚑ واكتب ملاحظتك عليه.
- **امتحان تجريبي**: 20 أو 40 أو 50 سؤال بوقت، موزعين بأوزان الامتحان، مع علامة «ارجعله قبل التسليم».
- **هدف يومي وعدّاد للامتحان** وخريطة نشاط لآخر 12 أسبوع.
- **السجل**: عملت إيه (لابات، دروس، فيديوهات) لكل المسارات.
- **بياناتي**: تنزيل واسترجاع التقدم كملف، ومظهر فاتح أو غامق.
- **اختصارات**: الأرقام للاختيار، Enter للتأكيد والتالي، F للعلامة.

## عن الأسئلة

الأسئلة **أصلية** ومكتوبة بأسلوب الامتحان على الـ [study guide الرسمي](https://learn.microsoft.com/en-us/credentials/certifications/resources/study-guides/az-104) (skills measured as of April 17, 2026). مفيش أسئلة مسرّبة (dumps). لو لقيت معلومة مختلفة عن Microsoft Learn، الـ docs هي المرجع.

## التشغيل

افتح `index.html` في المتصفح، أو فعّل GitHub Pages:
Settings ← Pages ← Deploy from a branch ← `main` / root.

## إضافة أسئلة

ضيف عنصر في أي ملف في `data/` (أو ملف جديد وضيف اسمه في `build.py` و `index.html`):

```js
{ id: "az104-194", s: "4.2", t: "single",   // single | multi | order | yn
  q: "Scenario…", c: "optional code",
  o: ["A", "B", "C", "D"], a: [1],
  e: `الشرح بالعربي` }
```

- `order`: اكتب الاختيارات بالترتيب الصحيح ومن غير `a`.
- `yn`: `o` هي العبارات و `a` فيها `1` أو `0` لكل عبارة.
- البطاقات في `SAHABA_CARDS`: `{ id, s, f: "الوش", b: "الضهر" }`.

`python build.py` بيعيد توليد `index.html` ونسخة ملف واحد `single.html`.

## التخزين

التقدم في `localStorage` على المتصفح بس. استخدم «بياناتي» للنقل بين الأجهزة.
